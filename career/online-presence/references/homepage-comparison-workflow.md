# Homepage Comparison Workflow

## Purpose
When user requests homepage improvement notes, analyze competitor homepages and provide specific, actionable recommendations for the Maxime Baudette homepage.

## Workflow Steps

### 1. Analyze Target Site
**Tools:** `browser_navigate`, `browser_vision`, `web_extract`

**Analysis Points:**
- **Design patterns:** Visual hierarchy, color schemes, typography, spacing
- **Content organization:** Information architecture, navigation structure, content flow
- **User experience:** Interactive elements, loading performance, mobile responsiveness
- **Technical implementation:** Framework, performance optimizations, accessibility features
- **Professional presentation:** Personal branding, academic/professional balance, call-to-action elements

**Data Collection:**
- Capture screenshots for visual reference
- Extract content structure and organization
- Note specific features or design elements
- Document loading performance and technical implementation

### 3. Provide Concise Recommendations
**Style:** Direct, actionable, no filler phrases

**Recommendation Structure:**
1. **High-impact improvements** (immediate wins)
2. **Medium-term enhancements** (substantial value)
3. **Long-term optimizations** (advanced features)

**Format:**
- Bullet points with specific actions
- Include file paths and implementation steps
- Reference exact elements to modify
- Avoid general suggestions like "improve design"

## Example Output Template

### High-Impact Improvements
- **Add emoji section headers** across all pages for visual hierarchy
- **Implement "say hi" CTA** in prominent position for engagement
- **Update CV data** with latest publications and experiences
- **Add hobbies/personal section** for personality and connection

### Medium-Term Enhancements  
- **Optimize homepage load time** by compressing images and minifying CSS
- **Add project showcase** with filtering capabilities for technical work
- **Implement dark mode** toggle for better accessibility
- **Add publication highlights** section for key research

### Long-Term Optimizations
- **Add blog section** for technical insights and thought leadership
- **Implement search functionality** for large content repositories
- **Add contact form** with professional inquiry routing
- **Integrate analytics** for performance monitoring

## Quality Standards
- **Specificity:** Recommend exact changes, not general improvements
- **Actionability:** Provide clear implementation steps
- **Conciseness:** Avoid filler phrases and unnecessary explanations
- **Professional tone:** Maintain appropriate academic/professional balance
- **User preference:** Embed direct communication style throughout
